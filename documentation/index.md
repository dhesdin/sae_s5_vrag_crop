# V-CROP RAG

SAE V-CROP RAG - recherche d'images par éléments constitutifs.

Cette documentation est découpée en deux parties :

- **Documentation utilisateur** : installer, indexer un dossier d'images,
  rechercher une image et comprendre un résultat.
  Point d'entrée : [Installation & lancement](utilisateur/installation.md).
- **Documentation technique** : architecture, schéma de données, choix
  techniques, stockage vectoriel et déploiement.
  Point d'entrée : [Architecture](technique/architecture.md).
